# My Qollab Test Project

A tiny HTML, CSS, and JavaScript demo for testing a GitHub repository link in Qollab.

## Files
- `index.html` — page structure
- `style.css` — visual styling
- `script.js` — button interaction

## Run locally
Open `index.html` in a web browser.

This is a simple web demo. Adding its repository URL to Qollab may only attach the repository link; it does not guarantee that Qollab can run this website.
